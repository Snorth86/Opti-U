# Validation record

Validation claims are revision-bound. This ledger records what a class of evidence establishes and, just as importantly, what it does not.

Reproducible commands, raw artefacts and source mappings are held with the private production repository. The results below are aggregated to protect internal topology, fixtures, schemas and implementation details.

| Validation area | Result | Supports | Does not establish |
|---|---|---|---|
| Controlled adversarial scenarios | 24 of 24 runs completed across three deterministic seeds, with no orchestration failures | Integrated operation and conservative response under controlled representative conditions | Live-user effectiveness or production scale |
| Heterogeneous export processing | 1,370 longitudinal daily records across three export families processed through evidence harnesses with no parse failures | Ability to normalise varied real-world export structures in the tested harnesses | Universal provider correctness or continuous production ingestion |
| Causal and sample-guard checks | 39 of 39 targeted checks passed; 25 were refusal/guard cases | Executable causal-estimation pathways and enforced minimum-evidence behaviour | Valid causal effects in a live population |
| Repository regression estate | Five-figure test collection on the evidence revision, exercised across primary and compatibility database paths | Breadth of software assurance on that revision | Product effectiveness, current evergreen test count or independent certification |
| Architecture evidence | Typed ownership, bounded influence and reproducible validation artefacts inspected against a named revision | Coherent governed implementation at TRL5 | Operational maturity at TRL6–7 |

## Evidence rules

1. Never publish a test number without its revision and scope.
2. Never present synthetic evidence as human-outcome evidence.
3. Never present an available code path as an operationally validated service.
4. Never present internal verification as independent assurance.
5. Publish limitations beside results, not in a distant footnote.
